基因型概率计算器

两个独立位点自交 n 代,可在每一代施加人工选择。默认从 F1 (AaBb) 开始,模拟亲本 AAbb × aaBB 杂交后的自交群体。

参数设置

每代保留的基因型 (人工选择)

未勾选的基因型在每一代繁殖前会被剔除并按剩余群体重新归一化。等同于:每一代播种前先做一次人工筛选。

查看模型说明

单位点自交转移矩阵(行 = 母代,列 = 子代):

          AA      Aa      aa
   AA  [  1        0       0  ]
   Aa  [ 0.25    0.50    0.25 ]
   aa  [  0        0       1  ]

两个位点独立 → 9 种基因型的转移矩阵 = 单位点矩阵的张量积(Kronecker product)。

每代流程: P_{n+1} = normalize(select(P_n · M))。 select 把未勾选基因型置 0,normalize 让概率和 = 1。
